# 安装指南（全能签）

完整图文版见 Release 附带的《月下酒馆 安装与使用指南》。这里是简要步骤。

## 安装包是什么

`MoonlitTavern-unsigned.ipa` 是真机（iphoneos）Release 构建，**没有签名**，里面没有证书和描述文件，iPadOS 不能直接安装。需要用全能签等工具配合你自己的证书重新签名。

| 项目 | 内容 |
|---|---|
| Bundle ID | `com.wuwuyou.moonlittavern` |
| 最低系统 | iPadOS 17.0（用 iOS 27.1 SDK 编译） |
| 设备 | 仅 iPad |
| 架构 | arm64 |
| 特殊权限 | 无 |

## 准备

- 签名证书 `.p12` 和它的密码。
- 配套的描述文件 `.mobileprovision`。开发证书或 Ad Hoc 证书的描述文件必须登记这台 iPad 的 UDID；企业证书不需要。
- 用开发证书签名时，iPad 要开启「设置 › 隐私与安全性 › 开发者模式」。

证书和描述文件只在你自己的 iPad 上使用，不需要提供给任何人。

## 步骤

1. 在 Releases 页面下载最新构建的 `MoonlitTavern-unsigned.ipa`，存到「文件」。
2. 用「共享」发送到全能签，或在全能签里导入该文件。
3. 在全能签里选择这个 IPA › 签名 › 选择你的证书。Bundle ID 保持不变。
4. 签名完成后点「安装」，回到主屏等待图标出现。

以后更新时，用**同一张证书、同一个 Bundle ID** 覆盖安装，数据才会保留。

## 内存权限说明

苹果的 `com.apple.developer.kernel.increased-memory-limit` 权限可以在部分机型上提高 App 的内存上限，但只有描述文件本身包含该能力时才可能生效。安装包默认不声明它。App 加载模型前会读取系统实际允许的内存，放不下 8K 上下文时自动降到 6K 或 4K 并提示。

## 装不上时

| 现象 | 常见原因 | 处理 |
|---|---|---|
| 安装失败、无法验证 | 描述文件没有这台 iPad 的 UDID | 换包含本机 UDID 的描述文件，或用企业证书 |
| 图标灰色、点开闪退 | 证书过期或被吊销 | 换有效证书重新签名 |
| 提示需要开发者模式 | 开发证书签名但未开启开发者模式 | 开启开发者模式后重启 |
| 签名失败 | p12 密码错误或全能签版本过旧 | 核对密码，更新全能签 |

> 安装流程没有经过实际测试。能否装上取决于证书类型、描述文件和证书状态。
