# 架构与关键设计

## 分层

| 层 | 位置 | 职责 |
|---|---|---|
| 界面 | `MoonlitTavern/UI` | SwiftUI 视图。左侧角色与存档，中间对话，右侧角色 / 世界书 / 记忆 / 参数 / 上下文五个面板 |
| 应用状态 | `MoonlitTavern/App` | 主线程上的状态与业务流程：发送、生成、重新生成、分支、摘要、模型加载、生命周期 |
| 推理 | `MoonlitTavern/Inference`、`MoonlitTavern/Providers` | `InferenceEngine` 协议；`LlamaEngine`（本地，llama.cpp）与 `OpenAICompatibleEngine`（云端）；模型库；设备内存读数 |
| 核心逻辑 | `Packages/MoonlitCore` | 角色卡、世界书、提示词组装、记忆、群聊调度、流式文本、GGUF 解析。不依赖 UIKit，可在 Linux 上测试 |
| 持久化 | `MoonlitCore/Persistence` | 每个角色、存档、世界书、记忆一个 JSON 文件，原子写入；损坏文件跳过并提示 |
| 安全 | `MoonlitTavern/Security` | 钥匙串保存 API Key |

## 架构要求的落实

| 要求 | 做法 |
|---|---|
| UI 与推理引擎解耦 | 视图只读写 `AppState`，不接触引擎 |
| 本地与云端统一接口 | 两个引擎实现同一协议，输出同一种事件流：阶段、文本增量、统计、结束 |
| 持久化与业务分离 | `TavernStore` 只负责读写，业务规则在 `AppState` 和核心库 |
| 角色卡独立测试 | `CharacterCardTests` 9 项，配样例文件 |
| 推理不阻塞 UI | llama.cpp 调用在独立串行队列；提示词组装在后台任务；界面按流式事件刷新 |
| 可取消 | 停止按钮或 ⌘ . 设置取消标记，每个 token 检查一次，已生成内容保留 |
| 后台、内存警告、卸载 | 进入后台立即停止推理（iPadOS 不允许后台提交 GPU 任务），可选同时卸载模型；内存警告时停止生成或卸载模型；模型管理可手动卸载 |
| 模型存放位置 | `Documents/Models`，「文件」App 可见，排除 iCloud 备份 |
| 不打包模型权重 | IPA 约 5 MB，模型单独下载或导入 |
| 第三方许可 | 见 `THIRD_PARTY_LICENSES.md` |

## 提示词拼接顺序

1. 系统提示词（角色自带优先，否则全局默认；支持 `{{char}}` `{{user}}` `{{original}}` 等宏）
2. 世界书「角色前」条目
3. 角色设定：当前发言者在前；群聊里其他角色省略背景与场景
4. 世界书「角色后」条目
5. 用户身份（persona）
6. 剧情状态
7. 长期记忆
8. 示例对话（只用剩余空间，最先舍弃）
9. 聊天历史，按深度插入「按深度」世界书条目、作者注释、角色卡 depth_prompt
10. 历史后指令；群聊追加「现在轮到某某发言」
11. 回复前缀（群聊预填「某某：」）

预算：可用空间 = 上下文长度 − 回复长度。世界书最多 30%，记忆最多 20%（且不超过各自设置值），其余给历史，最后剩下的给示例对话。历史从最早的消息截断，截断点保持稳定。

代码：`Packages/MoonlitCore/Sources/MoonlitCore/Chat/PromptBuilder.swift`

## 世界书激活规则

1. 过滤：禁用、内容为空、角色过滤不匹配、未到延迟条数、冷却中的条目不参与
2. 触发：常驻直接激活；粘滞期内保持激活；其余扫描最近 N 条消息的关键词（区分大小写、整词匹配仅对拉丁字母生效、正则 `/…/flags`）
3. 次要关键词：任一命中 / 全部命中 / 都不命中 / 未全部命中
4. 剧情状态条件：等于、不等于、存在、不存在、大于等于、小于等于
5. 概率
6. 递归扫描（条目可设「不被递归激活」「不触发递归」）
7. 互斥组：同组保留优先级最高的一条
8. 预算：按 常驻 ＞ 粘滞 ＞ 优先级 ＞ 插入顺序 保留
9. 输出：按位置分组，组内按插入顺序

代码：`Packages/MoonlitCore/Sources/MoonlitCore/Lorebook/LorebookEngine.swift`

## 长期记忆

- 旧消息被挤出上下文时自动总结，也可在记忆面板「立即整理旧消息」
- 产出：摘要、关键事件、关系变化、剧情状态更新
- 检索：置顶 → 最近两条摘要 → 其余按关键词重合（IDF 加权）、重要度、新近程度、是否涉及当前角色打分，在预算内注入
- 每条记忆可查看、编辑、置顶、删除
- 解析时过滤小模型照抄的占位词和示例句子

代码：`Packages/MoonlitCore/Sources/MoonlitCore/Memory/`

## 群聊

- 发言顺序：自然（被点名优先，否则最久没说话的）、轮流、按健谈度加权随机、手动
- 身份隔离：当前发言者设定在前；回合末尾提示轮到谁；预填发言者名字；其他角色与用户名字设为停止词
- 所有角色共享聊天历史、世界书、剧情状态

## 剧情选项

- 每次回复完整保存后，用同一个模型生成 3 个（可设 2–4 个）用户下一步的选择，存在这条回复上（`ChatMessage.suggestions`），重启后还在
- 请求沿用回复的提示词（系统设定 + 聊天历史到这条回复为止），去掉历史后指令，末尾追加一条说明，预填「1. 」；本地模型因此能复用已经算好的上下文
- 点选项即作为用户消息发出；笔形按钮先填进输入框；「换一组」只替换选项，不改回复；改写回复会清空它的选项
- 用户开始发送、重新生成、停止或收到内存警告时，正在生成的选项立即取消
- 代码：`MoonlitCore/Chat/ReplySuggestions.swift`、`App/AppState+Suggestions.swift`

## 防止「吞回复」

- 只有输出最开头的 `<think>` 算思考段；正文中间出现的思考标签只删标签，内容照常显示
- 思考段直到结束都没闭合：把这部分当正文放出（多半是模型把正文写进了思考段，或用完了长度上限）
- 孤立的 `</think>` 只删标签，不删它前面的正文
- 生成中途出错：已经显示出来的部分照样保存，并提示出错原因
- 清理后为空但原文有内容：改存只去掉标签的原文
- 每次回复在「诊断日志」写一行「回复定稿」：显示字数、清理后字数、停止原因、是否保存；命中停止词、隐藏思考段时另有记录
- 代码：`MoonlitCore/Chat/StreamingText.swift`（`StreamingTextFilter`、`ReplyFinalizer`）、`App/AppState+Generation.swift`

## KV 缓存复用与回退

- 比较新旧提示词的公共前缀，只计算新增部分
- 关闭思考模式时，历史中的助手消息也补空思考段，保证模板渲染前后一致
- 混合架构（Qwen3.5）不能按位置删除循环状态：保留最多 3 个状态快照（回复读完提示词时、回复生成完时、剧情选项读完提示词时），下一轮从其中最长、仍是新提示词前缀的那个接着算；重新生成只需重算 1 个 token

代码：`MoonlitTavern/Inference/LlamaEngine.swift`

## 云端模式与隐私

- 默认本地模式；云端需手动切换并配置
- 联网代码只在 `Inference/ModelLibrary.swift`（用户点击的模型下载）与 `Providers/OpenAICompatibleEngine.swift`（云端模式）中
- API Key 存钥匙串（仅本机、首次解锁后可读），界面只显示掩码，错误信息不回显请求头
