# 已知问题

| 问题 | 影响 | 处理 |
|---|---|---|
| 没有真机测试 | M4 iPad 上的速度、内存、发热都是未知数 | 按测试报告里的真机测试清单逐项测试，运行「设置 › 真机性能测试」并保存结果 |
| 全能签安装未验证 | 证书或描述文件不符时会装不上或闪退 | 见 `docs/INSTALL.md` 的排查表 |
| 默认不声明 increased-memory-limit | 8 GB 机型的可用内存以系统默认上限为准 | 描述文件带有该能力时，可在工程中加入该权限重新构建 |
| 断网推理未实测 | 代码上本地推理不联网，但没有在断网条件下跑过 | 真机上用飞行模式验证 |
| 摘要后下一次回复要重读提示词 | 记忆变化让 KV 缓存失效，那一轮首 token 变慢 | 计划把记忆移到提示词更靠后的位置 |
| 混合架构最多保留 3 个状态快照 | 回退到更早的位置时需要重读提示词 | 重新生成、停止后再发、选了剧情选项后的下一轮不受影响 |
| 小模型摘要质量有限 | 可能遗漏或编造细节 | 记忆可手动编辑；建议用 4B 模型 |
| 云端模式未连接真实服务测试 | 个别服务商的兼容细节可能有差异 | 出错时界面显示服务商返回的原文 |
| App 内下载未纳入自动化测试 | 下载流程只经过代码检查 | 也可以用 Safari 下载后导入，或直接放进 Models 文件夹 |
| 系统文件选择器在用户的 iPad 上不可用 | 先后试过三种实现，模拟器上都正常，用户真机上都用不了。诊断日志显示选择器弹出后只回了「已取消」，文件没有交给 App。怀疑与重新签名后系统文件服务和 App 之间的通信有关 | 新增备用选择器（SwiftUI 单选）、「共享 › 月下酒馆」和分屏拖入三条路，真机效果待确认；「粘贴 JSON」和「角色卡」文件夹两条路一直可用 |
| 「共享 › 月下酒馆」和拖入没有自动化测试 | 模拟器的 UI 测试驱动不了「文件」App 的共享菜单和跨 App 拖放 | 代码路径与其他导入方式共用，诊断日志会记下每一步 |
| 用户性别靠关键词判断 | 描述里没有明确用词，或者两种都出现时判断不出 | 身份设置里手动选「男」或「女」 |
| DRY 也会罚角色卡里的原话 | 角色的固定口头禅被照搬时会被压低 | 嫌口头禅出现太少，就在「参数」里调低 DRY 强度 |
| 剧情选项由模型生成 | 小模型偶尔给出重复、跑题或格式不对的选项；每轮多花几秒 | 点「换一组」重新生成，或直接输入；可在「参数」里关掉自动生成 |
| hf-mirror 是第三方镜像 | 可能限速或不可用 | 改用官方地址，或用其他设备下载 |
| 少见的对话模板 | 自动识别不到时回退到模型自带模板，个别模型可能格式错乱 | 在推理设置里手动选择模板 |
| 仓库已公开 | 代码、提交历史（含早期提交的作者邮箱）和 Releases 里的安装包对所有人可见 | 公开仓库使用 GitHub 自带机器构建不计费 |
